# Landing Page - Ana Luiza Nutricionista

Aplicação frontend em React + TypeScript + Vite + Tailwind CSS.

## 🚀 Como Executar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Abra `http://localhost:5173` no seu navegador.

## 📦 Como Gerar a Versão de Produção (para Deploy Gratuito)

```bash
npm run build
```

A pasta gerada **`dist/`** é um site estático pronto para publicação em serviços gratuitos como:
- **Vercel**
- **Netlify**
- **GitHub Pages**
- **Cloudflare Pages**
